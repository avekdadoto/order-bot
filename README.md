# Order Bot ☕

Telegram-бот для приёма заказов в маленьком бизнесе. Демо-пример — кофейня в Варшаве.

Покупатель выбирает товары, собирает корзину и оформляет заказ, не выходя из Telegram. Продавец получает заказ в личку и принимает или отклоняет его одной кнопкой, а покупатель сразу видит ответ.

## Что умеет

- **Каталог** с ценами и описаниями товаров
- **Корзина**: добавить, убрать, изменить количество, итоговая сумма
- **Оформление по шагам**: имя → телефон (кнопкой или вручную) → самовывоз или доставка с адресом → подтверждение
- **Уведомление продавцу** с кнопками «Принять» / «Отклонить»
- **Ответ покупателю** о статусе заказа
- **Сохранение заказов** в `data/orders.json`
- Защита: принять заказ может только продавец, заказ нельзя обработать дважды

## Технологии

- Node.js 18+ без сторонних библиотек: запросы к Telegram Bot API через встроенный `fetch`, long polling
- Тесты на встроенном `node:test`, Telegram в тестах заменён заглушкой

## Структура

```
catalog.json      товары, название и описание магазина
src/index.js      запуск, настройки, цикл получения сообщений
src/bot.js        экраны, кнопки, оформление заказа
src/shop.js       корзина и заказы (без Telegram, легко тестировать)
test/             тесты полного сценария заказа
```

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN`.
3. Запустите:
   ```
   npm start
   ```
4. Напишите боту `/id`, впишите полученное число в `ADMIN_ID` в `.env` и перезапустите. Теперь заказы будут приходить вам.

Тесты: `npm test`

## Под другой бизнес

Чтобы сделать бота для пиццерии, цветочного или барбершопа, достаточно поменять `catalog.json`: название, описание и список товаров. Код трогать не нужно.
